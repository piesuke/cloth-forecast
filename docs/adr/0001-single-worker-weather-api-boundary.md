# 天気APIと画面を単一Worker内で分離する

画面からはTanStack Startのサーバー関数を呼び、サーバー関数が秘密ヘッダーを付けたリクエストを同じWorker内の天気APIハンドラーへプロセス内で渡す。HTTPルートも同じハンドラーを使い、秘密ヘッダーが一致しない呼び出しを拒否する。Cloudflare Workersでは同じWorkerの公開URLを通常の `fetch` で呼び戻す構成に制約があり、API用Workerを別に増やすより単一デプロイを保てるため、この境界を採用する。

外部からHTTPルートを呼ぶこと自体は可能だが、秘密文字列を知らなければ天気データを取得できない。画面側のJavaScriptには秘密文字列を含めない。

画面から呼ぶサーバー関数は利用者から実行できるため、秘密ヘッダーは画面経由の利用回数を制限する仕組みではない。
